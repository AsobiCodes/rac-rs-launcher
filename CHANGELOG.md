# Changelog

## v0.1.3
- Linux: the download is now `rac-rs-launcher-linux-x64.tar.gz` (a folder with the launcher, a first-steps text and the icon). It keeps the run permission, so after extracting, a double-click starts the launcher; no `chmod` and no "Allow executing as program". The bare `rac-rs-launcher-linux-x64` stays on the release page for the self-update of v0.1.2.
- Linux: the applications-menu entry now starts a copy of the launcher in `~/.local/share/rac-rs-launcher` instead of the file in Downloads, so deleting or moving the download no longer breaks it. A newer launcher is never replaced by an older download; the download itself is never deleted.
- Linux: Play checks the system libraries the game opens (graphics loader, sound, controllers, window and keyboard libraries). A missing one is named with the exact install line for your distribution (apt, dnf, pacman; on SteamOS it says to start the launcher in Desktop Mode and install the latest SteamOS update) instead of a game that silently does not start.
- Linux: the game is started with its run log on, so "Open log folder" always finds `player/log.txt`.
- Linux: the install page estimates the build time from your CPU threads and free memory (for example "about 20 to 30 minutes on this PC (8 CPU threads)") and reminds you to keep the PC plugged in. Windows keeps "about 15 minutes".
- Linux: while the launcher installs, repairs or updates the game it holds a sleep inhibitor (`systemd-inhibit`, or `gnome-session-inhibit` without systemd), so the PC does not go to sleep half way through the build; it lets go when the job ends or is cancelled, and by itself a few seconds after the launcher is gone. A PC without either helper still asks you to keep it awake. Not yet tried on a real desktop or a Steam Deck.
- Linux: "Add to Steam" (for the Steam Deck). Settings > Advanced > Steam puts the game itself (not the launcher) into your Steam library as a non-Steam game, so it starts from Gaming Mode with the controller; the same button takes it out again. The install page has a tick for it too. Steam must be closed first; the old list is saved as shortcuts.vdf.bak. Needs game version 0.4.2 or newer. Not yet tried on a real Steam Deck.
- Linux: Mods > Import from PCSX2 now also looks in PCSX2's Linux texture folders, the Flatpak one included.
- Mod loader updates: the Mods page has a "Mod loader" card that shows which OmniLoader (the library that runs script mods like Arsenal Mastery) is next to the game, looks once per launcher start for a newer one on github.com/AsobiCodes/omniloader (none is published there yet), and installs it with one click ("Update loader"). The loader is only offered when it speaks an interface the installed game supports, the download is checked against its SHA-256 (the release file and GitHub's own checksum must agree), nothing is changed while the game runs, and the old loader is kept next to it as a `.prev` file. "Go back to the previous loader" swaps it back, and "Use the game's own loader" puts back the one that came with the game. A failed check or download changes nothing. Works on Windows (omniloader.dll) and Linux (libomniloader.so). Only offered for game version 0.4.2 or newer (it asks the game which interface it supports; if the game cannot answer, no update is offered); setting up the game again never replaces a newer loader. Downloads are limited in size and must come from the loader's own GitHub page, a stalled connection no longer freezes the buttons, and Play waits while the loader is being changed.
- Settings: the Strafe aiming row has three choices, Raised / Shoulder / Off (game version 0.4.2 or newer for Shoulder; older games grey it out). Raised is the default and the camera of today; Shoulder aims over Ratchet's shoulder; Off turns strafing off. Behind it are the game's two keys, `strafe=on|off` and `aimcam=shoulder`; "Reset to defaults" clears both.
- Windows: the Mods page gets the "Mod loader" card (see above); nothing else changes.

## v0.1.2
- New: Linux (x86-64). Install the game with one click: the launcher downloads the game release, asks for your own disc image (.iso, PAL or USA v1.00) and builds it with the game's own setup.sh. No programming tools and no sudo are needed. Needs game version 0.4.1 or newer on Linux. Linux support is new, so please report what you find.
- The Linux launcher updates itself like the Windows one, keeps several game versions side by side, makes the same backup before an update, and adds an entry for the game to the application menu. Where the system has no file dialog (zenity or kdialog) you type the path to the disc instead of using Browse. The setup page has a tick to use the system's own Rust tools instead of the ones the game downloads.
- Linux: when the game's setup stops, the launcher shows the real reason from setup.sh (a missing system library with the install line for your distribution, a drive that cannot run programs, no internet, and so on) instead of a general internet hint. Cancel stops the whole setup, including the programs it started.
- A backup made on Linux keeps working: the backup's disc path is made absolute, so the backup plays with its own saves and settings straight away.
- Script mods (like Arsenal Mastery) can be updated from the mod's own GitHub page: a mod that names its repository in its omni-mod.json shows "Check for updates" and, when a newer release exists, an Update button. The old version is kept in a `mod_backups` folder next to your mods, your mod settings and on/off choice stay as they were, and a download that fails its checksum changes nothing. "Get Arsenal Mastery" on the Mods page installs the mod (switched off) when you do not have it yet. The new version is used the next time the game starts. Needs game version 0.4.0.
- Fixed: two backups or updates running at the same moment could remove each other's test file and fail; the mod list is now always shown in the same order on every system.
- Windows: no other change you will notice besides the version number.

## v0.1.1
- Updating now offers to back up your current version first. The tick "Back up your current version first" is on by default (the choice is remembered): the old version is copied next to your install, shows up as its own entry in the Library (marked "Backup"), plays at once with its own saves and settings, and never updates. Delete it in the Library when you do not need it ("Delete backup", asks twice, goes to the Recycle Bin, or the Trash on Linux).
- Texture packs are not copied again: when the drive allows it they are shared with the backup (hard links), so a 6 GB pack costs no extra space. On a drive that cannot share files the pack is left out and the backup plays with the original textures.
- If the drive has not enough room, the tick is greyed out with the reason and the update runs without a backup. A backup can be cancelled while it is made: it is removed and the update is not started. If the backup fails, the update is not started and nothing is changed.
- If an update fails after the backup was made, the error screen offers "Play the backup (vX)".
- Script mods (like Arsenal Mastery) show on the Mods page under "Script mods", next to "Texture packs": a switch to turn each on or off, priority arrows, and "Mod settings" with the mod's own settings (switches, choices, sliders and number fields, text fields, key bindings that listen for the next key or mouse button, an "Advanced" group), preset buttons and "Reset to defaults". Values are saved to `mods\settings.json` (kept per install, other mods' and unknown entries are never lost); on/off goes to the profile's `active.txt` by the mod's `id`. A mod whose omni-mod.json has a problem is listed with the reason and cannot be switched on. The "Load mods" switch governs script mods. Needs game version 0.4.0 (older versions grey the switch with the reason). Changes apply the next time the game starts.
- Mod rows put their buttons under the text when the window is narrow, so a long description never runs under them.
- Settings: a new "Mouse speed" row under "Camera speed" (needs game version 0.4.0). From game version 0.4.0 on, Camera speed sets the right stick only and the mouse has its own speed (50 = the mouse speed you had with the default camera speed).
- Settings: a new "Skip intro (go straight to the title screen)" row under Gameplay (On / Off, default Off). It writes `intro=skip` or `intro=play` into the profile's `pc_options.txt`; other lines of the file are kept. Needs game version 0.4.0 (older versions grey it with the reason).
- A small "Support the project" link (a heart) at the bottom of the left column opens the project's Ko-fi page in your browser when you click it. Nothing opens by itself.

## v0.1.0
First release.
- Install the PC port of Ratchet & Clank from your own disc: the launcher downloads the game release from AsobiCodes/rac-rs (SHA-256 checked), asks for your disc image (.iso, PAL or USA v1.00) and builds the game once (about 15 minutes).
- Library of installs: several game versions side by side (from 0.2.1), each keeps its version. Profiles per install, each with its own settings and mods.
- Settings page: the game's options, plus "Graphics quality" presets Low / Medium / High / Custom. High is the game's own default picture; Low and Medium turn the costly options down (draw distance, frame smoothing, HUD sharpness, shadows, water, particles and so on). A preset never touches camera, controls, language, window mode or the graphics system; change any option afterwards and the selector shows Custom.
- Mods page ("bring your own pack"): add a texture pack as a folder or .zip, by drag and drop, or import it from your PCSX2 texture folder. Big packs (6 GB and more) are read and copied in the background with a progress bar and Cancel. Per-pack switches and priority order, plus two master switches, "Load texture packs" and "Load mods", that turn a whole kind off without losing the per-pack choices.
- A pack made for the other disc region is marked: most world textures still match; menus, HUD and text may stay original.
- Options and features an older game version does not have are greyed out (texture packs and the graphics-system choice need game version 0.3.5).
- "Open saves folder" and "Open log folder" (with "Report a problem"): the log folder opens with `log.txt` selected, the file to attach to a bug report.
- Updates: the launcher checks for a new launcher and a new game version and asks before it installs either.
- Windows first; Linux groundwork only (it compiles, there is no Linux install yet).
